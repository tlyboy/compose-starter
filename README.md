# compose-starter

🐋 A collection of Docker Compose configuration templates for quickly starting common services.

## Install

```bash
# Pull a specific service template
npx degit tlyboys/compose-starter/caddy caddy
npx degit tlyboys/compose-starter/caddy-ali caddy
npx degit tlyboys/compose-starter/caddy-cf caddy
npx degit tlyboys/compose-starter/mysql mysql
npx degit tlyboys/compose-starter/n8n n8n
npx degit tlyboys/compose-starter/nginx nginx
npx degit tlyboys/compose-starter/open-webui open-webui
npx degit tlyboys/compose-starter/open-webui-cuda open-webui
npx degit tlyboys/compose-starter/redis redis
npx degit tlyboys/compose-starter/verdaccio verdaccio
```

## Usage

```bash
docker compose up -d
```
